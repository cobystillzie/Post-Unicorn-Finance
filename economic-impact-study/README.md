A self-contained study folder inside the Post-Unicorn Finance operation, **isolated from the atlas**
(`../data/evidence/`). **Focused (2026-06-19)** on Ethan's directive: *before* comparing funds, first

## Current question (Ethan's baseline)

> **Is meaningful employee value participation — ESOPs, broad equity, profit-sharing — becoming a trend
> across startups? And where does the conversation sit in new PE and VC?**

SpaceX is a clean example of the *concept* (broad employee liquidity) but it is **not a startup** — the test
is whether *actual startups* are adopting this and whether it is rising.

## Method (free stack — no paid scraping)

- **Social listening on the free stack:** X (your cookies), web (Claude WebSearch + Exa + Brave), Hacker
  News, YouTube, GitHub, Polymarket; Reddit / LinkedIn / blogs reached **via web search**. ScrapeCreators
  (paid → TikTok/Instagram/native-Reddit) is **off**.
- **Discipline:** every claim needs a real URL + verbatim quote; separate ESOP *ownership plan* from startup
  option *pool*; report rising / flat / unclear honestly; social = discovery, then verify; don't bypass logins.
