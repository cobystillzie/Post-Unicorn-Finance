# Data Strategy — Public-First Pilot, Licensed-Later Scale

Per the 2026-06-17 directive, the Phase-0 pilot uses **public / compliant sources only** — no ToS-violating scraping. This document also compiles the **provider × metric × cost matrix** so a licensed provider can be integrated in Phase 2, *after* Ethan reviews the first 20-vs-20.


## Metrics the study needs

- Employee **headcount** (current + historical) — for jobs and per-dollar metrics
- **Capital raised / deployed** (whole-portfolio) — the per-dollar denominator
- **Ownership / cap-table** split — for the distribution metric
- **Exits / valuations**, **founding date**, **sector**, **geography** — matching + outcomes

## Recommendation

- **Phase 0–1 (now):** lean on the free/public stack (SEC EDGAR, DOL Form 5500 for ESOPs, NCEO, Companies House, company disclosures). It covers headcount, ESOP presence, founding, sector, and geography for many firms — but leaves private cap-table splits and private-company capital figures thin. Those gaps are the pilot's main finding (see `../analysis/pilot_first_cuts.md`).
- **Phase 2 (after Ethan's go-ahead):** add ONE licensed provider that covers headcount history + funding + ownership in a single feed. Decide the provider against the cost column above and the budget Ethan sets (see `05_questions_for_ethan.md`, Q6).
